# Electron by Nerc

**An independent Minecraft: Java Edition launcher for Windows.**

Electron by Nerc is a personal desktop software project designed to provide a customized Minecraft launching experience.

The project combines game profile management, mod discovery, installation tools, and a custom interface inspired by Minecraft voxel art and industrial science fiction.

## Project Status

The launcher is under active development.

Some features and external integrations are still being tested. Microsoft authentication and access to Minecraft Services have not yet been fully verified in production.

## Features

- Custom Electron desktop interface.
- Minecraft game profile management.
- Mod discovery and installation through supported repositories.
- Vanilla and Fabric profile support.
- Java and game configuration settings.
- Local settings and profile management.
- Minecraft-inspired industrial voxel-art environments.
- Discord Rich Presence integration, subject to configuration and testing.

Feature availability depends on the current development version.

## Microsoft Authentication

The launcher is designed to use Microsoft's authentication services and Minecraft Services to authenticate eligible Minecraft: Java Edition users.

The intended process includes Microsoft OAuth, Xbox Live authentication, Minecraft Services authentication, and verification of the user's Minecraft profile and game access.

Approval for the application's Minecraft Services Client ID has not yet been confirmed.

The project does not intend to bypass authentication or Minecraft ownership verification.

## Privacy and Security

The application may process account authentication data, Minecraft profile information, local game profiles, settings, and information required by enabled integrations.

See [Privacy Policy](PRIVACY.md) for more information.
