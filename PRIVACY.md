# Privacy Policy — Electron by Nerc

Last updated: October 14, 2026

Electron by Nerc is an independent Minecraft: Java Edition launcher currently under development.

## Information and Data

The application may process the following information when the corresponding features are used:

- Microsoft account authentication data required to establish a Minecraft session.
- Minecraft profile information required by supported launcher features.
- Local game profiles, settings, mod lists, and diagnostic logs.
- Requests to external services used for mod discovery, authentication, and other enabled integrations.

## Authentication

Microsoft authentication is intended to use Microsoft's supported authentication services.

Authentication credentials and tokens must be handled using the application's configured secure storage mechanism. Users should never share authentication tokens or session files.

## External Services

Depending on the enabled features, the application may communicate with Microsoft, Minecraft Services, Modrinth, CurseForge, and Discord.

These services process requests according to their own terms and privacy policies.

## Local Data

Game profiles, local worlds, settings, and downloaded modifications may be stored on the user's computer.

Before releasing the application, the developer will document the actual storage locations and retention behavior of sensitive authentication data.

## Contact

For privacy questions, please open an issue in the project's GitHub repository.

## Project Status

This policy describes the intended behavior of a project under development. It must be updated whenever the application's actual data collection or storage practices change.
