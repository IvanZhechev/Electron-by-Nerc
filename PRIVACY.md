# Privacy Policy — Electron by Nerc

Last updated: October 14, 2026

Electron by Nerc is an independent Windows desktop launcher for Minecraft: Java Edition currently under development.

## Information Processing

Depending on the features used, the application may process:

- Microsoft authentication information required to establish a Minecraft session.
- Minecraft profile information needed by the launcher.
- Local game profiles, configuration settings, and mod lists.
- Diagnostic logs used to investigate application errors.
- Requests to external services used for authentication, mod discovery, and optional integrations.

## Authentication

The application is intended to use supported Microsoft authentication and Minecraft Services mechanisms.

Authentication credentials and tokens must be handled using the application's configured secure storage mechanism. Users should never share passwords, authentication tokens, or session files.

## External Services

Depending on enabled features, the application may communicate with Microsoft, Minecraft Services, Modrinth, CurseForge, and Discord.

These services process requests according to their own terms and privacy policies.

## Local Data

Game profiles, settings, and downloaded modifications may be stored on the user's computer.

The exact storage locations and retention behavior of authentication data should be documented according to the application's actual implementation.

## Contact

For privacy-related questions, please use the GitHub Issues section of the project repository.

## Project Status

This policy describes the intended behavior of a project under development. It must be updated if the application's actual data processing or storage practices change.
